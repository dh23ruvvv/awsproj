# FlowPilot — Agent Entry Point

Start here:

1. Read `docs/05_AGENT_PROTOCOL.md` for operating rules.
2. Read `docs/04_TASK_BOARD.md` STATE block for current milestone and agent mode.
3. Pick the next TODO task assigned to your owner role.
4. Read only the sections listed in the task's `READ ONLY` field.
5. Follow the `IMPLEMENT`, `ACCEPTANCE`, and `VERIFY` instructions exactly.
6. Report per the format in `docs/05_AGENT_PROTOCOL.md` §3.

Do not read other documents unless your current task explicitly references them.
